基于深度相机的物体点云拼接与目标检测

SUN RGB-D 数据集 · VoteNet + YOLOv8n · 流水线总览（代码骨架，实验数值待运行回填）

① 数据预处理 preprocess/

解析 SUN RGB-D
parse_sunrgbd.py
读取图像/深度/标注/外参，输出帧 RGB+K npz
深度 → 点云
depth_to_pointcloud.py
深度图反投影 + 去噪 + 下采样，输出每帧点云
帧对采样
sample_frame_pairs.py
SUN3D 序列按间隔 5/10/30 抽取帧对
位姿真值
compute_pose_gt.py
由外参计算帧间 6DOF 相对位姿 T_AB
检测数据
generate_detection_data.py
生成 VoteNet 训练数据（投票标签/真值框）

② 点云拼接 registration/（纯 CPU）

预处理
preprocess_pointcloud.py
统计去噪 · 体素降采样 · 法向量估计
粗配准
coarse_registration.py
FPFH + RANSAC，输出初始变换
精配准
fine_registration.py
改进 ICP：点到平面 + 自适应阈值 + 早停
评测
evaluate_registration.py
RMSE / 旋转 / 平移 / 成功率
可视化
visualize_registration.py
拼接前后对比图

③ 三维目标检测 detection/（V100 GPU）

点云分支
votenet_baseline.py
VoteNet 主干（PointNet2）种子点特征
图像分支
yolov8_feature.py
YOLOv8n P3 层 80×80×64 语义特征
投影采样
projection.py
3D 种子 → 2D 双线性采样图像特征
融合头
fusion_head.py
Concat / Cross-Attention 特征融合
训练
train_fusion.py
冻结双主干，只训融合头+检测头（60 epoch）
轻量化
lightweight_head.py
DSConv1d 深度可分离头，通道 256→128
微调
finetune_lightweight.py
基于融合权重微调 20 epoch
评测
evaluate_detection.py
mAP@0.25/0.5 · 参数量 · FLOPs · 速度
